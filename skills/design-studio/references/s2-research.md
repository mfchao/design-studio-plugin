# Section 2: Research

Goal: the few theories and competitors that actually change design decisions. One short report.

## Run two subagents in parallel

Give each: the absolute path of `brief.md`, its output path, the date.

- **`theory-researcher`** → `.design-studio/research-theory.md`: 3 to 5 principles, laws or standards that most affect this brief. One line each: principle → implication for this design → source.
- **`benchmark-researcher`** → `.design-studio/research-benchmark.md`, images in `.design-studio/refs/bench/`: 4 to 6 products, 4 to 6 reference screens (desktop), patterns to adopt/avoid, gaps to own.

In lean mode, run only `benchmark-researcher` and add 3 theory bullets yourself.

## Merge and present

1. Write `.design-studio/research.md`. **Cap: 350 words.** Structure:
   - **Key takeaways** (≤ 5 bullets)
   - **Principles** (table: principle | implication)
   - **Landscape** (table: product | strength | weakness | pattern worth noting)
   - **Opportunities** (≤ 4 bullets, each tied to an objective)
2. Show the takeaways and opportunities in chat, with the path. Don't build a benchmark moodboard unless asked.
3. Section gate. "More here" means: dig into one competitor or question with one researcher.

## Fallbacks

If an MCP server is unreachable, use WebSearch only and note it in one line.
